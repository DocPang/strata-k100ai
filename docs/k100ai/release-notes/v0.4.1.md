## 2. 本版核心优化清单（7 个源码文件，净变更 `+1548 / -658`）

1. **双卡 128 GiB（GGUF 2.00bpw · 交错 YOCO 流水线）**：
   - `DS4_YOCO_INTERLEAVE=1`（`grp0: L[0..9, 21..30]`、`grp1: L[10..20, 31..39]`）配合单调跨段 `hand_seq` 与远程 KV 合并发布，实现双卡无损流水并行。
   - `wmma_gemm_mmac928.cuh` 寄存器预取 + 8-wave `128×128` 稠密 GEMM（Shared Expert `-23.0%`）；`ds4_attn_mmac928.inc` 双缓冲消冗余屏障（`6 → 2`）；`ds4_qsa_mmac928.inc` `uint4` 载入与 `float4` 预取（`-8 KiB` LDS）；`ds4_iq.cu` 去除 `dq_rows_kernel` 内循环 `__threadfence_block()`。
2. **四卡 256 GiB（EXL3 2.9bpw · 无锁 P2P + 零 LDS 寄存器 Shuffle）**：
   - **Lock-Free 1-Shot P2P Direct AllReduce（`STRATA_DS4_AR_P2P=1`）**：Decode 小消息（≤ 256 KiB）直连 P2P，避开 `hipStreamWaitValue32` 死锁风险。
   - **Prefill FP16 RCCL（`DS4_AR_RCCL_F16=1`）+ `NCCL_P2P_LEVEL=SYS` + 纯 NUMA0（`DS4_CPU_NUMA_NODES=0`, `DS4_NUMA_INTERLEAVE=0`）+ FP16 Router Cache（`STRATA_DS4_ROUTER_F16=1`）**。
   - **`exl3.cu` `K=1/2/3/4` `shfl32()` 零 LDS 寄存器 Shuffle**：利用 Wave64 `__shfl(v, src_lane, 32)` 消除 `sm.stage` LDS 往返与 2× `__syncwarp()`——Draft 单轮 **`-13%`**（`6.03 → 5.33 ms`）、32K Verify **`-4.0 ms`**（`53.02 → 49.05 ms`）、4K/32K Prefill 各省 **`100 ms`**。
   - **DSpark 调度优化（`dspark_conf=0.2` + `STRATA_DS4_DSPARK_FALLBACK_VERIFY=1`）**：彻底消除退化回 plain step（`0 plain`），4K Decode 无损提速至 **`73.29 tok/s`**（exact `MATCH`）。

## 3. 已验证并彻底剔除的死路（未纳入 v0.4.1）

- **`W8A8 INT8 Dense Cache (16x16x32i8 MMAC)`**：32K Prefill 仅省 254 ms（+1.6%），4K Prefill 反慢 52.5 ms，且导致 4K 退化为两 token 死循环、32K 仅出 6 token 提前 `stop`。
- **`EXL3 BM=64`**：MoE 平均每专家仅 14.6–28.6 行，4K/32K Prefill 分别退化 `-14% / -10.3%`。
- **`DSpark draft_t=7 (T=8)`**：单轮路由 unique experts 多 ~35%，Verify 耗时暴涨 `+25%`（`61.58 ms`），净收益为负。
- **`dspark_conf=0.0`**：关闭早停导致 4K Decode 退化 `-15%`（`61.06 tok/s`）。

## 4. 原生 Docker 快速启动（双卡 / 四卡）

### 4.1 双卡 128 GiB（GGUF 2.00bpw · 交错 YOCO）

```bash
docker run -d --name strata-dsv41-tp2 \
  --device /dev/kfd --device /dev/dri/renderD128 --device /dev/dri/renderD129 \
  --group-add video --ipc=host --shm-size 32g \
  -p 127.0.0.1:18097:18097 -w /app \
  -v /opt/hyhal:/opt/hyhal:ro \
  -v "$REL_DIR:/app:ro" \
  -v /data/models/dsv41-2.00:/models:ro \
  -e DS4_PROF=0 -e DS4_YOCO=1 -e DS4_YOCO_INTERLEAVE=1 \
  -e DS4_ATTN_SLAB=1024 -e DS4_ATTN_SPLIT=1 -e STRATA_DS4_DSPARK_FALLBACK_VERIFY=1 \
  --entrypoint /bin/bash "$DTK_IMAGE" \
  -lc 'exec python3 -m serve.server --engine strata --config /app/configs/k100ai/gguf-tp2-v041.json --host 0.0.0.0 --port 18097 --no-api-key'
```

### 4.2 四卡 256 GiB（EXL3 2.9bpw · 全显存常驻 + 无锁 P2P）

```bash
docker run -d --name strata-dsv41-tp4 \
  --device /dev/kfd \
  --device /dev/dri/renderD128 --device /dev/dri/renderD129 \
  --device /dev/dri/renderD130 --device /dev/dri/renderD131 \
  --group-add video --ipc=host --shm-size 32g \
  -p 127.0.0.1:18098:18098 -w /app \
  -v /opt/hyhal:/opt/hyhal:ro \
  -v "$REL_DIR:/app:ro" \
  -v /data/models/dsv41-exl3-2.9bpw:/models:ro \
  -e NCCL_P2P_LEVEL=SYS -e STRATA_DS4_AR_P2P=1 -e DS4_AR_RCCL_F16=1 \
  -e STRATA_DS4_ROUTER_F16=1 -e DS4_CPU_NUMA_NODES=0 -e DS4_NUMA_INTERLEAVE=0 \
  -e STRATA_DS4_DENSE_MMAC928_M128=0 -e DS4_ATTN_SLAB=1024 -e STRATA_DS4_DSPARK_FALLBACK_VERIFY=1 \
  --entrypoint /bin/bash "$DTK_IMAGE" \
  -lc 'exec python3 -m serve.server --engine strata --config /app/configs/k100ai/exl3-tp4-v041.json --host 0.0.0.0 --port 18098 --no-api-key'
```
