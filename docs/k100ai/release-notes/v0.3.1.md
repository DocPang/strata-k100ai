# Strata for K100AI v0.3.1 发布说明

v0.3.1 新增 Qwen3.8-Flash-Next IQ3_S 单卡精确引擎。32K 输入、256-token
输出的四轮发布测试中，原生 Decode 中位 45.8 tok/s，MTP Decode 中位
70.0 tok/s，Prefill 为 2,837.3–2,869.4 tok/s。DeepSeek-V4.1-Flash
沿用 v0.3.0 的引擎和三套配置。

[下载 v0.3.1](https://github.com/DocPang/strata-k100ai/releases/tag/v0.3.1)

## 1. 本版升级

### 1.1 新增 IQ3_S 精确引擎

`strata-qwen-iq3s-r112` 面向单张 K100AI 64 GiB，使用 IQ3_S 原生 GGUF、
EXL3 外的 Qwen 原生专家布局、INT8 KV 和完整 top-10 路由。发布模板冻结
以下生产参数：

```text
--kv-resident 65536
--max-context 65536
--spec 3
--spec-min-p 0.5
--mtp-window 4096
--mtp-q4 all
--no-publish-kernel
--suffix-draft 0
STRATA_PREFILL_TOPK=10
```

`--no-publish-kernel` 把 QSA step/pos 状态从逐元素读取 volatile mapped
host 内存改为 pinned host 内存上的异步 DMA。该变更只更换传输机制，不改变
权重、量化、归约顺序或采样结果。

`scripts/k100ai/serve-k100ai.sh qwen` 在 v0.3.1 默认启动 IQ3_S。
`qwen-iq3s` 是同一入口的显式别名。旧 IQ3_XXS 快速档改用
`qwen-iq3xxs`，0.1.55 对照档继续通过 `K100AI_QWEN_ENGINE` 显式切换。

### 1.2 精确算法边界

本版新增的 IQ3_S 引擎没有启用以下近似 Prefill 路径：

- `STRATA_PREFILL_TOPK` 固定为完整路由的 `10`。源码中的 6/8 专家截断是
  opt-in 近似路径，本版模板不启用。
- QSA top-k 使用精确阈值、确定性的并列顺序和最低 index 规则。H16 radix
  仅改变键的表示与选择遍数，选择结果与父实现相同。
- `--suffix-draft 0`。prompt-lookup 后缀投机被关闭，MTP 只使用外置 draft
  layer。
- MTP 只提出候选，目标模型执行验证后才提交 token。发布测试中，每个
  Native / MTP 配对的 256-token 输出 SHA-256 完全相同。

“无近似算法”描述本版新增 IQ3_S 推理路径。模型权重仍使用 IQ3_S 量化，
它不等同于未量化的 BF16/FP16 模型。v0.3.0 的 DeepSeek R178 自适应
Prefill 配置保持原状，并继续受原发布说明中的精度门禁约束。

### 1.3 gfx928 Qwen 路径

R112 引擎包含以下已验证的 gfx928 Qwen 路径：

- QSA prompt attention 的精确 MMAC 路径和完整分数选择。
- IQ2_S/IQ3_S/IQ4_NL 专家 gate/up 与 down 的原生 fused+LDS 布局。
- Q6_K dense 权重采用列不变解码和 wave-local LDS 路径。
- Q8_1 量化、R26 scale fusion、R38 auxiliary GEMV 和 conv+AB 融合。
- 模型中的 10 个 IQ3_S/IQ4_NL 层走默认 mode 8 的 fused+LDS 对。旧的
  s26 路径保留为 `STRATA_S26=1` 显式开关。
- 65,536-token KV 全驻留，避免 32K 请求在 decode 阶段跨 PCIe 读取 KV。

## 2. 成绩与口径

### 2.1 公共测试条件

| 项目 | fixed 值 |
| --- | --- |
| 机器 | 单张 Hygon K100AI 64 GiB，HCU0 |
| 模型 | Qwen3.8-Flash-Next GSQ-RCO IQ3_S |
| 输入 | 32,768 prompt tokens |
| 输出 | 256 tokens |
| 温度 / 采样 | temperature 0，greedy |
| prompt cache | 0 |
| conversation cache | 0 |
| KV | INT8，65,536 驻留，65,536 最大上下文 |
| Prefill chunk | 20,480 |
| expert cache | 24,576 slots |
| MTP | spec 3，min-p 0.5，window 4096，Q4 all |
| 质量门禁 | input exact、output exact、retrieval |

每项重复 4 次，不使用同一次服务热缓存。四个 Native 请求与四个 MTP
请求使用相同 prompt、seed 和输出 token 数。

### 2.2 Decode

| 模式 | 4 次实测 tok/s | 中位 | 相对原生 |
| --- | --- | ---: | ---: |
| Native，无 drafter | 45.7 / 45.8 / 45.8 / 45.9 | **45.8** | 1.00× |
| MTP，spec 3 | 70.8 / 68.4 / 71.7 / 69.2 | **70.0** | **1.53×** |

MTP 四次接受数为 `132/188`、`128/193`、`133/180`、`128/185`。不同
prompt 内容会改变接受率，因此发布只承诺上述样本的区间
`68.4–71.7 tok/s`，不把 `71.7` 当作固定速度。

四个 Native 请求每 token 用时为 `21.877 / 21.819 / 21.824 / 21.797 ms`，
中位 `21.8215 ms/token`。四个 MTP 请求为
`14.133 / 14.627 / 13.946 / 14.441 ms/token`，中位 `14.287 ms/token`。

### 2.3 Prefill

## 4. 安装与启动

下载后先校验完整发布包：

```bash
BASE=https://github.com/DocPang/strata-k100ai/releases/download/v0.3.1
curl -fLO "$BASE/strata-k100ai-v0.3.1.tar.gz"
curl -fLO "$BASE/strata-k100ai-v0.3.1.tar.gz.sha256"
sha256sum -c strata-k100ai-v0.3.1.tar.gz.sha256
tar -xzf strata-k100ai-v0.3.1.tar.gz
cd strata-k100ai-v0.3.1
sha256sum -c SHA256SUMS
```

安装运行环境并准备 IQ3_S 资产：

```bash
bash scripts/k100ai/setup-runtime.sh
K100AI_ASSETS_DIR=/data/k100ai-assets \
  bash scripts/k100ai/fetch-qwen-iq3s.sh \
  /data/k100ai-assets/qwen3.8-flash-next-iq3-s
```

启动 IQ3_S 精确档：

```bash
K100AI_ASSETS_DIR=/data/k100ai-assets \
PORT=18096 \
  bash scripts/k100ai/serve-k100ai.sh qwen
```

启动前默认检查：

```text
$K100AI_ASSETS_DIR/qwen3.8-flash-next-iq3-s/pack/iq3s
$K100AI_ASSETS_DIR/qwen3.8-flash-next-iq3-s/model/IQ3_S
$K100AI_ASSETS_DIR/qwen3.8-flash-next-iq3-s/mtp/rt
data/k100ai-qwen-iq3s-draft-vocab-zh60k.bin
```

也可用以下环境变量逐项覆盖资产目录：

```text
K100AI_QWEN_PACK
K100AI_QWEN_NATIVE
K100AI_QWEN_PLE
K100AI_QWEN_TOKENIZER
K100AI_QWEN_MTP_RT
K100AI_QWEN_MTP_VOCAB
```

## 6. 限制

- 本次成绩来自单卡、greedy、32K 输入和 256 输出。其他上下文、并发数、
  采样设置和 prompt 内容需要重新测量。
- 70.0 tok/s 是 MTP 四次中位。接受率随内容变化，68.4–71.7 tok/s 是本批
  样本的观测区间。
- 本版新增引擎的“精确”指完整 top-10、精确 QSA 选择和目标模型验证 MTP。
  它不声明 IQ3_S 权重与未量化模型逐位相同。
- DeepSeek 配置仍对应 v0.3.0 的 R179 生产状态，不纳入本次 Qwen 精确性
  结论。
