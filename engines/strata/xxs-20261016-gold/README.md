# IQ3_XXS 优化引擎（gold）：2026-10-16

本目录对应 v0.1.0-rc.6，分发 `43002a7262e5` 固定引擎，完整摘要和大小见 [manifest.json](manifest.json)。

相对上一版 [xxs-20261016](../xxs-20261016/README.md)（`d87a4678a21b`），本版在 prefill 与 decode 两条路径上继续做了增量优化：

- `STRATA_GEMM_Y_F16=qkv|qf|sg|su|sd|z`：六个投影族的 GEMM Y 累加器改走 16 位路径。同批 A/B/A 实测 250K −3.43%、32K −5.49%，输出逐位一致；这是本版的主要收益来源。
- `STRATA_TOPK_H16=1` + `STRATA_TOPK_REG_MAX=7168`：topk 走 2-pass h16 核，并用寄存器缓存最大值，减少每轮的重复扫描。
- `STRATA_SCORES_MMAC_NB` 由 `1` 改为 `2`：scores 矩阵计算的合并批次翻倍。
- `STRATA_Q6_WAVE_PACK_LDS=1`：Q6K packed-wave 走 LDS 路径（decode）。
- `STRATA_MMVQ_WV2_GROUP=1`：MMVQ WV2 分组。

## 已否决、未纳入本引擎

- `STRATA_TOPK_H16_T`（把 h16 topk 核的线程数从 256 提到 1024）：250K 下实测整模 **+11.96%**、qsa select **+86%**（相对未启用 `REG_MAX` 的基线）；以只启用 `REG_MAX` 的中间引擎（142,119 ms）为基线则是 **+13.7%**。同批次 6 个臂的输出 SHA 完全一致，说明回归纯粹出在性能而非结果。源码保留默认关闭的实例化，键不设置。

## 性能与校验范围

[benchmarks.json](benchmarks.json) 保存四类记录：打包时对**正在运行的生产引擎**做的验证请求、定版时的单开关同批 A/B/A、整版对上一版的同批 A/B/A、以及部署后的在线验证请求。条件各不相同，不可混用：

- 打包验证（生产卡 HCU0）：约 39K token 输入 20.38 s、约 66K token 输入 25.73 s；短提示 + 300 token 输出，TTFT 0.70–1.06 s。
- 整版同批 A/B/A（2026-10-17，本版对上一版 rc.5，同卡同批）：32K 15.620 → **14.885 s / 2,055.9 tok/s**（−4.70%）、128K 70.715 → **65.848 s / 1,926.6 tok/s**（−6.88%）、250K 146.780 → **137.249 s / 1,821.4 tok/s**（−6.49%），每档两个版本输出逐位一致。
- 单开关同批 A/B/A（2026-10-16 定版批次）：250K 142,360.6 → **137,476.4 ms / 1,818.4 tok/s**（`GEMM_Y_F16`，−3.43%）；32K 15,833.55 → **14,964.35 ms / 2,045.1 tok/s**（−5.49%）。
- 解码（32K 入 + 128 token 出）区间 74.6–84.4 tok/s，同一臂内两个样本也会相差约 5%。
