# Optional requirements

Core Python dependencies remain in the repository's `requirements.txt`. These optional files are kept under packaging because they are build or component-specific:

| File | Use |
| --- | --- |
| `packaging/requirements/requirements-build.txt` | Local engine and image-encoder build tools |
| `packaging/requirements/requirements-monitor.txt` | Optional terminal monitor |
| `packaging/requirements/requirements-nvfp4-local.txt` | Local NVFP4 conversion and packing |
