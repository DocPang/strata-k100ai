# Strata for K100AI v0.3.2

[安装指南](../INSTALL.md) · [运行参数](../RUNTIME.md) · [复现指南](../REPRODUCIBILITY.md)

Qwen3.8-Flash-Next IQ3_S 默认上下文提高到 **262,144 tokens**，其中 **65,536 个
KV 位置驻留在显存**。更长请求需要的 KV 块按需从主机内存读取。默认 API 模型名为
`qwen3.8-flash-next`。

- Qwen 继续使用 v0.3.1 的 R112 二进制。旧 IQ3_XXS 引擎和 DeepSeek 引擎、配置沿用原版本。
- 首页按模型、安装、卡数、实测和 API 接入整理。安装、运行、配置、版本与 Issue 帮助入口均已更新。
- 发布包恢复固定的 `gguf-py`，归档内外均有 SHA-256。Git 检出提供基于指定提交打包的命令。
- 发布包提供 32K 和接近 256K 的固定检索验证命令，保存实际 token 数、输出 SHA-256、时延及吞吐。
- [v0.3.1 的 32K R112 实测](v0.3.1.md)与 [v0.3.0 的 DeepSeek 成绩](v0.3.0.md)继续作为原版本记录。
