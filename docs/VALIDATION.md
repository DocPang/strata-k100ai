## 已有环境证据

前版已在 Linux amd64、固定 DTK 镜像上完成无 GPU 的派生镜像构建，内部文件校验、服务导入、动态库、四个工具入口和 mock HTTP/SSE 检查通过。相关产物与运行包在本版复用。

c4 历史 IQ3_S 服务及早期 IQ3_XXS 服务使用过相同基线。2026-10-15 复核时，IQ3_S 服务仍为 c4，XXS 线上服务已使用 `ad743dbf…` 实验二进制；该实验产物不属于本 Release，不能将其性能归到本版 c4 配置。

历史 c4 的 47 请求、4 次进程启动记录对应 32K context、prefill30602。当前参考配置为 prefill20480、max-context262144，需按当前配置分别验收。

## 限制

- 256K 为配置上限，延迟、并发与稳定性需按实际负载验证。
- KV、工作区和专家数据估算不是总显存峰值。
- IQ3_XXS 的新增类型可使用通用路径，专用优化覆盖与 IQ3_S 不同。
- 不同驱动、DTK 或基础镜像需要重新验证兼容性。
- FP16 中间结果及可选控制向量会影响输出；性能检查不能替代质量检查。

源码恢复详细状态见 [replay/validation.json](../engines/strata/c4/replay/validation.json)。各 Release 资产保留原始内容。
