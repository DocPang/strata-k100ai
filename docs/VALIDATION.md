# v0.1.0-rc.1 验证范围

本页区分历史运行证据、此次交付验证和仍未完成的验收。候选版不承诺所有 K100AI 机器得到相同速度。

## 此次交付已完成

- 从冻结的历史发布文件取得引擎，SHA-256 为 `c4be512a7d257d9b56bc325136431e5feffd2b6d76f52378051829bfe73fc903`。
- 运行包中的 174 个 Strata serve/tools/data 文件逐一对照冻结 c4 源码清单，哈希一致；另包含固定 llama.cpp 的 gguf-py 与上游许可证。
- 运行包压缩大小 8,504,874 字节；摘要见 [artifact.sha256](../engines/strata/c4/artifact.sha256)。不包含模型、DTK/HyHAL 库或主机配置。
- 在算力服务器 Linux amd64、固定官方 DTK 镜像上，使用本地基础 tag、`--local-only` 和已缓存运行包成功构建；没有执行 apt/pip，也没有挂载 GPU。
- 镜像构建校验内部文件 SHA-256，并成功导入实际服务模块及其 Python 依赖。
- 新镜像内 `ldd` 未发现缺少动态库，冻结引擎 `--help` 可执行。
- `iq_pack.py`、`mtp_fetch.py`、`mtp_pack.py`、`mtp_rt.py` 的容器工具入口可调用 `--help`。
- 缺少 API key 时，服务入口按预期拒绝启动。
- 新镜像的 mock 后端通过 `/health`、非流式 chat 和 SSE 完成标记检查；仅证明前端打包可用，不代替真实模型接口测试。
- 本地单元/安装契约测试通过：参数替换、显式控制向量、无效输入、缺少离线基础镜像、错误基础镜像、篡改运行包、离线安装不拉取且不启动服务。
- 默认启动器已用实际模型路径、pack、MTP 和设备节点通过 `--check` 检查，未启动新推理容器。
- 当前算力服务器未安装 Compose 插件，因此默认提供直接使用 `docker run` 的启动器；可选 Compose 配置尚未在目标服务器验证，可在具备 Compose v2 的环境运行 `docker compose --env-file deployment.env.example config --quiet`。

上述测试没有切换现有服务，没有占用 GPU 进行推理或完整权重转换。
